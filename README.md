A single sentence, at most 200 characters, written by a small deterministic Python program for make.fun's "The Meeting That Should Have Been One Line" bounty. The program writes the sentence to `/output/entry.txt` and self-checks it against the gate (1–200 characters, one line, no extra whitespace) before exiting.

The line: this meeting could have been an email, and the email could have been a single word — yes.

## Run it

```sh
python3 main.py
```

Set `ENTRY_OUTPUT` to write somewhere else for local testing, e.g. `ENTRY_OUTPUT=/tmp/entry.txt python3 main.py`.
